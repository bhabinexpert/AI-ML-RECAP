Deep Learning II — Convolutional Neural Networks (CNN)

Dense (fully connected) layers treat every pixel as an independent feature and ignore spatial structure. CNNs fix that — they're built specifically to understand images.

7.1 Why not just use a regular ANN on images?

Problems with a plain ANN on images

  • A 224×224 color image has 150,528 pixels — flattening it into one dense layer creates an enormous number of weights, extremely prone to overfitting
  • Flattening destroys spatial relationships (a nose is only meaningful near eyes/mouth)
  • No translation invariance — a shifted object looks like a totally different input

What CNNs do instead

  • Small filters slide across the whole image, sharing the same weights everywhere (parameter sharing → far fewer weights)
  • Preserves 2D spatial structure between layers
  • Learns local patterns (edges → shapes → objects) that generalize regardless of position in the image

7.2 The Convolution Layer

Definition
A convolution layer slides a small matrix of learnable weights (a filter / kernel, e.g. 3×3) across the input image. At each position, it computes the element-wise product between the filter and the patch of image underneath it, sums the results into a single number, and places that number into an output grid called a feature map.
Output size = ((N − F + 2P) / S) + 1
N = input size, F = filter size, P = padding, S = stride — this formula (below) tells you the feature map's width/height for any combination of these.
import tensorflow as tf
tf.keras.layers.Conv2D(filters=32, kernel_size=(3,3), activation="relu", padding="same")

7.3 Padding & Strides

Padding

Without padding, the output shrinks after every convolution, and pixels at the border are used in far fewer computations than center pixels (information loss at the edges). Padding adds a border of zeros around the input before convolving.

  • Valid padding — no padding added; output shrinks each layer.
  • Same padding — enough zero-padding is added so the output has the same width/height as the input.

Stride

The number of pixels the filter moves each step. Stride 1 moves one pixel at a time (dense, overlapping coverage, larger output). Stride 2 skips every other position (output shrinks roughly by half, faster computation, less overlap).

Rule of thumb
Larger stride ≈ cheaper computation and smaller output, but risks skipping fine detail. "Same" padding + stride 1 is the common default in early layers when you want to preserve spatial resolution.

7.4 Pooling Layers

Definition
Pooling downsamples a feature map — reducing its width and height while keeping the most important information — which cuts computation, reduces overfitting, and adds a small amount of translation invariance.
  • Max Pooling — takes the maximum value in each window. Most common — keeps the strongest activation (the clearest sign a pattern was detected).
  • Min Pooling — takes the minimum value; rarely used in practice.
  • Average Pooling — takes the mean of the window; smooths the feature map, sometimes used in later/final layers (e.g. Global Average Pooling before the output).
tf.keras.layers.MaxPooling2D(pool_size=(2,2), strides=2)

7.5 Stacking Layers: Full CNN Architecture

A typical CNN repeats Conv → Activation (ReLU) → Pooling multiple times, each block learning progressively more abstract features:

  • Early layers detect simple patterns — edges, corners, color blobs.
  • Middle layers combine those into textures and simple shapes.
  • Deep layers combine shapes into object parts (eyes, wheels, wings).

After several conv+pool blocks, the resulting feature maps are flattened into a 1D vector and fed into one or more fully connected (dense) layers — the same kind of layer from Module 06 — which combine all the learned features to make the final classification.

Python — a complete small CNN in Keras
import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Conv2D(32, (3,3), activation="relu", padding="same", input_shape=(64,64,3)),
    tf.keras.layers.MaxPooling2D((2,2)),

    tf.keras.layers.Conv2D(64, (3,3), activation="relu", padding="same"),
    tf.keras.layers.MaxPooling2D((2,2)),

    tf.keras.layers.Conv2D(128, (3,3), activation="relu", padding="same"),
    tf.keras.layers.MaxPooling2D((2,2)),

    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(128, activation="relu"),
    tf.keras.layers.Dense(10, activation="softmax")   # 10-class classification
])

model.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
model.summary()

Official reference: TensorFlow's CNN tutorial walks through this exact pattern on the CIFAR-10 dataset with full training code.

Advantages of CNNs

  • Far fewer parameters than a dense network on the same image, thanks to weight sharing
  • Learns spatial hierarchies automatically — no manual feature engineering on pixels
  • Translation-invariant pattern detection

Disadvantages

  • Still needs a lot of labeled data to train from scratch
  • Computationally expensive to train (benefits heavily from GPUs)
  • Not naturally invariant to rotation/scale without data augmentation
Check your understanding
Why do CNNs use far fewer parameters than a dense network processing the same image? (Answer: a convolution filter's weights are shared across every position in the image — the same small filter slides everywhere — instead of a dense layer needing a unique weight for every single pixel-to-neuron connection.)

7.6 Where to go from here

You've now covered the full arc: data → classical ML → ensembling → unsupervised methods → NLP → neural networks → CNNs. Natural next steps beyond this roadmap: Recurrent Neural Networks (RNN/LSTM) and Transformers for sequential data, transfer learning with pretrained CNNs (ResNet, VGG, EfficientNet), and word embeddings (Word2Vec, BERT) to go deeper into NLP.
