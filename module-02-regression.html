Regression & Optimization

Linear regression is the simplest supervised algorithm — and understanding it fully (the math, not just the sklearn call) unlocks how nearly every other model, including neural networks, is trained.

2.1 What is a Regression Algorithm?

Definition
A regression algorithm predicts a continuous numeric value (price, temperature, salary) from one or more input features, by learning a mathematical function that maps inputs to outputs.

Real examples: predicting house price from square footage, predicting a student's exam score from hours studied, predicting delivery time from distance and traffic.

2.2 Linear Regression — Building the Best-Fit Line

Definition
Linear regression assumes the target is a weighted sum of the input features plus an intercept — i.e., a straight line (or hyperplane, in higher dimensions) fits the relationship.
ŷ = w·x + b
ŷ = predicted value, x = input feature, w = weight (slope), b = bias (intercept)
With multiple features: ŷ = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

Mathematical Intuition — how do we find "best"?

We need a way to score how wrong a line is, then find the w and b that minimize that wrongness. That score is the cost function.

2.3 The Cost Function

Definition
A cost function (a.k.a loss function, when per-sample) measures the average error between the model's predictions and the actual values. Training = finding parameters that make this number as small as possible.
J(w, b) = (1/n) Σᵢ (yᵢ − ŷᵢ)²
This is Mean Squared Error (MSE) — square the residual so positive/negative errors don't cancel out, and large errors are penalized more heavily than small ones.
n = number of data points, yᵢ = actual value, ŷᵢ = predicted value

J(w, b) is a function of the parameters w and b — plot it, and for linear regression with MSE it forms a smooth, bowl-shaped (convex) surface. Training means walking down that bowl to its lowest point.

2.4 Gradient Descent & the Global Minimum

Definition
Gradient Descent is an iterative optimization algorithm: it repeatedly nudges the parameters in the direction that most reduces the cost function, using the function's gradient (slope) as a compass.
Repeat until convergence:
w := w − α · ∂J/∂w
b := b − α · ∂J/∂b
α (alpha) = learning rate — how big a step to take each iteration

Intuition: imagine standing on a hilly, bowl-shaped surface in fog, trying to reach the bottom. You feel which direction is downhill right where you stand (the gradient) and take a step that way. Repeat, and you eventually reach the bottom — the global minimum, the point of lowest possible cost.

Choosing the learning rate α
Too small → training crawls, takes forever to converge. Too large → steps overshoot the minimum and the cost can bounce around or even diverge (increase). This is why learning rate is one of the most important hyperparameters to tune.
Python — gradient descent from scratch
import numpy as np

def gradient_descent(X, y, lr=0.01, epochs=1000):
    n, m = X.shape
    w = np.zeros(m)
    b = 0.0
    for _ in range(epochs):
        y_pred = X @ w + b
        error = y_pred - y
        dw = (2/n) * (X.T @ error)      # ∂J/∂w
        db = (2/n) * np.sum(error)       # ∂J/∂b
        w -= lr * dw
        b -= lr * db
    return w, b

In practice you'll use the optimized library version:

from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X_train, y_train)
predictions = model.predict(X_test)

2.5 Evaluating a Regression Model

MetricFormula (intuition)Notes
MAEAverage of |y − ŷ|Easy to interpret, treats all errors equally
MSEAverage of (y − ŷ)²Penalizes large errors heavily; same units as y²
RMSE√MSEBack in the original units of y — most commonly reported
R² (R-squared)1 − (SS_residual / SS_total)% of variance in y explained by the model; 1.0 = perfect, 0 = no better than predicting the mean
from sklearn.metrics import mean_squared_error, r2_score
rmse = mean_squared_error(y_test, predictions, squared=False)
r2 = r2_score(y_test, predictions)

2.6 Overfitting & Underfitting

UnderfittingOverfitting
CauseModel too simple, too few features, too much regularizationModel too complex, too many features, trained too long, too little data
Training errorHighVery low
Test errorHighHigh (large gap vs. training error)
FixAdd features, use a more complex model, reduce regularizationMore data, regularization (L1/L2), simpler model, dropout, early stopping, cross-validation
The bias-variance tradeoff
Underfitting = high bias (wrong assumptions, misses patterns). Overfitting = high variance (overly sensitive to the specific training sample). The whole art of model-building is finding the sweet spot between the two.
