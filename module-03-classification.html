Classification Algorithms

Predicting categories instead of numbers — from a straightforward probability model (logistic regression) to distance-based, probabilistic, tree-based, and margin-based approaches.

3.1 Logistic Regression

Definition
Despite the name, logistic regression is a classification algorithm. It predicts the probability that an input belongs to a class, by squashing a linear combination of features through the sigmoid function.

Why not use linear regression for classification?

A straight line can predict values below 0 or above 1, which makes no sense as a probability, and it's very sensitive to outliers shifting the decision boundary. We need an S-shaped function that always outputs between 0 and 1.

The Sigmoid Activation Function

σ(z) = 1 / (1 + e^(−z)), where z = w·x + b
As z → +∞, σ(z) → 1. As z → −∞, σ(z) → 0. At z=0, σ(z)=0.5.

The decision boundary is drawn where the model's linear function z = w·x + b equals a threshold (usually σ(z)=0.5, i.e. z=0). Above it → predict class 1; below → predict class 0.

Log Loss (Binary Cross-Entropy) — the cost function

MSE doesn't work well here (it makes the cost surface non-convex with sigmoid). Instead we use log loss, which heavily penalizes confident-and-wrong predictions.

J(w,b) = −(1/n) Σᵢ [ yᵢ·log(ŷᵢ) + (1−yᵢ)·log(1−ŷᵢ) ]
If the true label yᵢ=1 and the model predicts ŷᵢ close to 0 → −log(ŷᵢ) is huge (large penalty).
If the prediction matches the true label confidently, the loss for that point → 0.

This cost is minimized with gradient descent, exactly as in Module 02.

from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
model.fit(X_train, y_train)
probs = model.predict_proba(X_test)   # probability per class
preds = model.predict(X_test)         # thresholded class label

3.2 Evaluating a Classifier

Confusion Matrix

MetricFormulaAnswers the question
Accuracy(TP+TN) / (TP+TN+FP+FN)Overall, what fraction did we get right? (misleading on imbalanced data)
PrecisionTP / (TP+FP)Of everything we flagged positive, how much was actually positive?
Recall (Sensitivity)TP / (TP+FN)Of all actual positives, how many did we catch?
F1 Score2 · (Precision·Recall)/(Precision+Recall)Harmonic mean — balances precision and recall in one number
Precision vs. Recall — which matters more?
Spam detection: false positives (good email marked spam) are costly → prioritize precision. Cancer screening: missing a real case (false negative) is far worse than a false alarm → prioritize recall. 
from sklearn.metrics import confusion_matrix, classification_report
print(confusion_matrix(y_test, preds))
print(classification_report(y_test, preds))  # precision, recall, f1 in one call

3.3 K-Nearest Neighbors (KNN)

Definition
KNN classifies a new point by looking at the K closest points in the training data (by distance, usually Euclidean) and taking a majority vote of their labels. It is a lazy learner — it doesn't "train" a model; it just memorizes the data and computes at prediction time.
distance(a, b) = √( Σᵢ (aᵢ − bᵢ)² ) — Euclidean distance 
from sklearn.neighbors import KNeighborsClassifier
model = KNeighborsClassifier(n_neighbors=5)
model.fit(X_train, y_train)  # scale features first — KNN is distance-based!

Advantages

  • Simple, no training phase
  • Naturally handles multi-class problems
  • Non-linear decision boundaries

Disadvantages

  • Slow at prediction time on large datasets
  • Sensitive to feature scale (must scale first)
  • Struggles in high dimensions ("curse of dimensionality")

3.4 Naive Bayes

Definition
A probabilistic classifier based on Bayes' Theorem, which assumes every feature is conditionally independent of every other feature given the class — an assumption that's almost never exactly true in reality (hence "naive"), yet the algorithm performs surprisingly well in practice, especially for text.
P(class | features) = [ P(features | class) · P(class) ] / P(features)
We pick the class that maximizes P(class | features).
from sklearn.naive_bayes import MultinomialNB
model = MultinomialNB()
model.fit(X_train_counts, y_train)  # classic use-case: spam detection on word counts

Advantages

  • Extremely fast to train and predict
  • Works well with high-dimensional data (text)
  • Needs relatively little training data

Disadvantages

  • Independence assumption is usually false
  • Can be outperformed by more complex models when features are correlated

3.5 Decision Trees

Definition
A decision tree splits the data repeatedly on feature thresholds (like a flowchart of yes/no questions) until it reaches a "pure" group, or a stopping condition — the model is fully interpretable by walking the tree.

How the tree decides what to split on: Entropy & Information Gain

Entropy(S) = − Σᵢ pᵢ · log₂(pᵢ)
pᵢ = proportion of class i in set S. Entropy = 0 when the set is pure (all one class); entropy is maximum (1.0 for binary) when classes are perfectly mixed 50/50.
Information Gain = Entropy(parent) − Σ (|child|/|parent|) · Entropy(child)
The tree tries every possible feature/threshold split and picks the one with the highest information gain — i.e. the split that makes the resulting groups purest.

Steps to build a decision tree

  1. Calculate entropy of the current node (before splitting).
  2. For every feature and every possible threshold, calculate the information gain of splitting there.
  3. Choose the split with maximum information gain.
  4. Repeat recursively on each child node.
  5. Stop when a node is pure, hits max depth, or has too few samples to split further.
from sklearn.tree import DecisionTreeClassifier
model = DecisionTreeClassifier(criterion="entropy", max_depth=5)
model.fit(X_train, y_train)

Advantages

  • Easy to interpret and visualize
  • No feature scaling needed
  • Handles both numeric and categorical data

Disadvantages

  • Prone to overfitting if left unpruned (grows too deep)
  • Unstable — small data changes can produce a very different tree

3.6 Support Vector Machine (SVM)

Definition
SVM finds the hyperplane (a line in 2D, a plane in 3D, a higher-dimensional surface beyond that) that separates classes with the widest possible margin — the largest gap to the nearest points of each class.

Support Vectors

Only the data points closest to the boundary — the support vectors — actually determine where the hyperplane sits. Every other point could be removed without changing the boundary at all.

The Kernel Trick

When classes aren't linearly separable in the original space, SVM can implicitly map data into a higher dimension where a straight hyperplane does separate them — without ever explicitly computing that transformation (the "kernel trick"). Common kernels: linear, polynomial, and RBF (Radial Basis Function).

from sklearn.svm import SVC
model = SVC(kernel="rbf", C=1.0)
model.fit(X_train, y_train)  # C controls margin-hardness vs. misclassification tolerance

Advantages

  • Effective in high-dimensional spaces
  • Memory-efficient (only stores support vectors)
  • Kernel trick handles non-linear boundaries

Disadvantages

  • Slow to train on large datasets
  • Requires careful feature scaling
  • Choosing the right kernel/C/gamma takes tuning
