Module 09 · Deep Learning

Deep Learning IV — Transformers

LSTMs fixed vanishing gradients but still process a sequence one step at a time — slow, and still lossy over very long ranges. The Transformer architecture (2017, "Attention Is All You Need") removes recurrence entirely and is the foundation behind every modern LLM.

9.1 Sequence-to-Sequence Models & the Context Vector

Definition
A Seq2Seq model maps an input sequence to an output sequence of possibly different length (e.g. translating a 5-word English sentence into a 7-word French one). The classic (pre-Transformer) design uses two RNNs/LSTMs: an encoder that reads the whole input and compresses it into a single fixed-size vector, and a decoder that generates the output from that vector.
The problem: the context vector is a bottleneck
Squeezing an entire sentence — or paragraph — into one fixed-size vector loses information, and the problem gets worse the longer the input is. By the time the decoder is generating word 20, it's working from a blurry summary of everything, with no way to "look back" at exactly which input word mattered most for the word it's generating right now. This was the direct motivation for attention.

9.2 The Attention Mechanism

Definition
Instead of forcing the decoder to rely on one fixed summary, attention lets it look back at every input position at every generation step, and learn how much weight to place on each one for the specific word it's currently producing.

Example: translating "The cat sat on the mat" → when generating the French word for "cat", attention lets the model assign high weight to "cat" and low weight to "mat", "sat", etc. — directly, without routing everything through one compressed vector first.

9.3 Embeddings

Definition
An embedding is a dense vector of real numbers that represents a token (word/sub-word) such that semantically similar tokens end up close together in vector space — a major upgrade over the one-hot/BoW/TF-IDF vectors from Module 05, which treat every word as equally unrelated to every other word.

Embeddings are learned during training (or pretrained separately, e.g. Word2Vec, GloVe) — the model discovers that "king" and "queen" should sit near each other, and famously that vector arithmetic like king − man + woman ≈ queen often holds approximately true.

tf.keras.layers.Embedding(input_dim=vocab_size, output_dim=256)

9.4 The Transformer Architecture

Definition
The Transformer keeps the encoder-decoder idea from Seq2Seq but replaces recurrence entirely with self-attention, letting it process every position in a sequence in parallel instead of one step at a time — much faster to train, and much better at long-range dependencies.

Steps, end to end

  1. Tokenize the input text into sub-word tokens.
  2. Embed each token into a dense vector.
  3. Add positional encoding — a pattern of sine/cosine values (or learned vectors) added to each embedding, since self-attention itself has no built-in notion of word order.
  4. Pass through N encoder blocks, each doing multi-head self-attention followed by a feed-forward network, with residual ("Add") connections and layer normalization ("Norm") around each.
  5. The decoder generates output tokens one at a time, using masked self-attention (a token can't attend to future tokens it hasn't generated yet) plus attention over the encoder's output.
  6. A final linear layer + softmax converts the decoder's output vector into a probability distribution over the vocabulary — the next predicted token.
Why positional encoding, layer norm & residual connections matter
Self-attention treats a sequence as an unordered set unless position is injected explicitly — hence positional encoding. Residual ("skip") connections let gradients bypass a block entirely during backprop, directly fighting the vanishing gradient problem in very deep stacks (Module 06). Layer normalization stabilizes the scale of activations between blocks, making deep stacks trainable.

9.5 Query, Key, Value & Self-Attention

Definition
Self-attention computes, for every token, three vectors — a Query (what am I looking for?), a Key (what do I contain?), and a Value (what information do I actually offer?) — all as learned linear projections of the same input embedding.
Attention(Q, K, V) = softmax( Q·Kᵀ / √dₖ ) · V
Q·Kᵀ — every query is compared (dot product) against every key, producing a similarity score between every pair of tokens.
/ √dₖ — scaling to keep gradients stable (dₖ = dimension of the key vectors).
softmax — converts scores into attention weights that sum to 1 per query.
· V — the final output is a weighted sum of all Value vectors, weighted by how relevant each token is to this query.

Intuition: think of it like a search engine. The Query is your search term, the Keys are the index terms of every document, and the Values are the actual document contents. You match your query against every key to get relevance scores, then combine document contents weighted by relevance.

Multi-Head Attention

Instead of computing attention once, the model runs several attention "heads" in parallel, each with its own learned Q/K/V projections — one head might learn to track grammatical structure, another might track coreference (which noun a pronoun refers to). Their outputs are concatenated and combined.

import torch.nn as nn
attn = nn.MultiheadAttention(embed_dim=512, num_heads=8)
output, weights = attn(query, key, value)

Official reference for the original architecture: "Attention Is All You Need" (Vaswani et al., 2017).

9.6 The Feed-Forward Network (inside each block)

Definition
After attention mixes information across tokens, each token's resulting vector is passed through the same small feed-forward network (two dense layers with a ReLU/GELU in between) — independently, position by position — adding extra representational capacity per token.
FFN(x) = max(0, x·W₁ + b₁)·W₂ + b₂

9.7 Autoregressive vs. Non-Autoregressive Generation

Autoregressive (AR)
Generates output tokens one at a time, each new token conditioned on all previously generated tokens (this is how GPT-style models write text — predict the next word, append it, repeat). Accurate and coherent, but inherently sequential and slower at inference.
Non-Autoregressive (NAR)
Generates all output tokens in parallel in one shot, trading some accuracy/coherence for a large speed-up — used in some fast translation and speech synthesis systems where latency matters most.

Why does the decoder need masked self-attention but the encoder doesn't? (Answer: the encoder sees the full input at once — there's nothing to hide. The decoder generates output one token at a time and, during training, must not be allowed to "see" future tokens it hasn't generated yet — masking blocks attention to future positions so training matches how the model actually generates at inference time.)
