Full Roadmap Summary

Everything above, compressed to the one idea per topic worth remembering. Use this page for a fast recap — if any line doesn't fully make sense, that's your cue to revisit that module.

01 ML Foundations & Feature Engineering

  • ML = learning a function from examples instead of hand-coding rules. AI ⊃ ML ⊃ DL.
  • Supervised (labeled data: regression/classification) vs. unsupervised (no labels: clustering/dim. reduction) vs. reinforcement learning (reward-driven trial and error).
  • EDA: understand shape/types → descriptive stats → univariate/bivariate analysis → missing values → outliers → correlations.
  • Pipeline: problem → data → EDA/clean/preprocess → feature engineering → split → train → evaluate → tune → deploy (a loop, not a line).
  • Cleaning fixes correctness (duplicates, wrong types, missing values); preprocessing fixes format (encoding, scaling) — always fit transformers on train data only, to avoid leakage.
  • Encoding: Label/Ordinal (order matters), One-Hot (no order, few categories), Target encoding (high cardinality).
  • Scaling: Standardization (mean 0, std 1, robust to outliers) vs. Normalization (bounded 0–1, sensitive to outliers). Tree models don't need scaling; distance/gradient-based models do.
  • Feature selection: Filter (fast, statistical, model-agnostic) → Wrapper (uses model performance, e.g. RFE) → Embedded (built into training, e.g. Lasso, tree importances).

02 Regression & Optimization

  • Linear regression: ŷ = w·x + b — find w, b that minimize the cost function.
  • Cost function (MSE) = average squared residual; training = minimizing this over all data.
  • Gradient descent: repeatedly step opposite the gradient (w := w − α·∂J/∂w) to reach the global minimum. Learning rate α controls step size — too small is slow, too large diverges.
  • Evaluate with MAE, MSE, RMSE, R².
  • Underfitting = high bias (too simple); overfitting = high variance (memorizes noise). The bias-variance tradeoff is the central tension in all of ML.

03 Classification Algorithms

  • Logistic regression: sigmoid squashes a linear function into a 0–1 probability; trained with log loss (binary cross-entropy), not MSE.
  • Confusion matrix → Accuracy, Precision (of predicted positives, how many correct), Recall (of actual positives, how many caught), F1 (harmonic mean of the two).
  • KNN: classify by majority vote of the K nearest points — needs feature scaling, no real "training" phase.
  • Naive Bayes: Bayes' theorem + (naive) feature independence assumption — fast, strong on text.
  • Decision Trees: split on the feature/threshold with highest Information Gain (entropy reduction); interpretable but prone to overfitting unpruned.
  • SVM: finds the max-margin hyperplane; only support vectors matter; kernel trick handles non-linear boundaries.

04 Model Tuning & Ensemble Learning

  • Cross-validation: average performance over K train/test rotations — more reliable than one split.
  • GridSearchCV (exhaustive) vs. RandomizedSearchCV (samples combinations, cheaper at scale) for hyperparameter tuning.
  • Bagging (parallel, reduces variance) → Random Forest = bagged trees + random feature subsets per split.
  • Boosting (sequential, reduces bias): AdaBoost re-weights misclassified samples; Gradient Boosting fits new trees to residual errors; XGBoost = regularized, optimized gradient boosting.
  • Stacking: train a meta-model to combine predictions from several different base models.

05 Unsupervised Learning & NLP

  • K-Means: assign → recompute centroid → repeat; choose K via the elbow method. Assumes spherical, similar-sized clusters.
  • DBSCAN: density-based, finds arbitrary shapes, auto-detects outliers, no need to pre-specify K.
  • PCA: compress features into variance-ranked components — gains speed/visualization, loses direct interpretability.
  • NLP pipeline: get data → clean text (lowercase, remove stopwords, lemmatize) → tokenize → vectorize → model.
  • Vectorization: One-Hot (presence only) → Bag of Words (adds frequency) → TF-IDF (also down-weights common words). None capture meaning or order — that's what embeddings and Transformers solve.

06 Deep Learning I — ANN

  • Perceptron: weighted sum + bias → activation. Stacked perceptrons in layers = ANN.
  • Forward prop computes the prediction; backprop uses the chain rule to compute ∂Loss/∂weight for every weight, layer by layer, backward.
  • Vanishing gradients: many layers of small derivatives multiplied together shrink toward zero — early layers stop learning. Motivates ReLU over sigmoid/tanh in hidden layers.
  • Activations: Linear (regression output), Sigmoid (binary output), Tanh (zero-centered, still saturates), ReLU (default hidden layer, can "die"), Leaky ReLU/PReLU (fix dying ReLU), Swish (smooth, strong on deep nets).
  • Losses: MAE/MSE/MSLE (regression), Binary/Categorical Cross-Entropy (classification).
  • Optimizers: Batch GD (stable, slow) → SGD (fast, noisy) → Mini-batch (practical default) → Momentum (smooths path) → AdaGrad (adapts LR per parameter, shrinks forever) → Adam (momentum + adaptive LR — today's default).

07 Deep Learning II — CNN

  • Convolution layer: a small filter slides across the image, weight-sharing keeps parameter count low, output is a feature map.
  • Padding ("same" vs "valid") controls output size and border information loss; stride controls how far the filter moves each step.
  • Pooling (usually Max) downsamples feature maps, reduces computation, adds mild translation invariance.
  • Architecture: repeated Conv→ReLU→Pool blocks (simple → complex features) → Flatten → Dense layers → output.

08 Deep Learning III — RNN / LSTM / GRU

  • Sequential data: order carries meaning. RNNs carry a hidden state hₜ forward across time steps, reusing the same weights at every step (parameter sharing over time).
  • Vanilla RNNs suffer vanishing/exploding gradients across long sequences (BPTT multiplies gradients across every time step) — they forget long-range context.
  • LSTM fixes this with a cell state ("memory highway") plus Forget/Input/Output gates that control what's kept, added, and exposed.
  • GRU simplifies LSTM to two gates (Update, Reset) and one merged state — fewer parameters, comparable performance on many tasks.

09 Deep Learning IV — Transformers

  • Seq2Seq (encoder→context vector→decoder) bottlenecks all information into one fixed-size vector — attention removes that bottleneck by letting the decoder look at every input position directly.
  • Embeddings represent tokens as dense vectors where similar meanings sit close together — a major upgrade over One-Hot/BoW/TF-IDF.
  • Self-attention: Attention(Q,K,V) = softmax(Q·Kᵀ/√dₖ)·V — every token compares its Query against every other token's Key to decide how much of each token's Value to absorb.
  • Multi-head attention runs several attention computations in parallel, each learning different relationships.
  • Transformer block = Multi-Head Attention → Add & Norm → Feed-Forward Network → Add & Norm, stacked N times; positional encoding injects order since attention alone is order-blind; residual connections fight vanishing gradients in deep stacks.
  • Decoder uses masked self-attention (can't see future tokens) + attention over the encoder's output.
  • Autoregressive generation (GPT-style: one token at a time, conditioned on all previous tokens) vs. non-autoregressive (all tokens at once — faster, sometimes lower quality).

— The One Thread Running Through All 10 Modules

Every model in this roadmap does the same three things: (1) turn raw input into numbers, (2) combine those numbers through learnable weights, and (3) adjust those weights using gradient descent to reduce a loss function. Linear regression, logistic regression, a neural network, an LSTM, and a Transformer are all, underneath, gradient descent on a loss function — they differ mainly in how they combine the numbers (a line, a sigmoid curve, layers of neurons, a gated memory cell, or an attention-weighted sum). Once that thread clicks, every new architecture is a variation on a theme you already understand.
