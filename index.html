Note: While this serves as a quick, handy reference, it shouldn't be your only resource. Always explore comprehensive courses, papers, and hands-on projects to deepen your mastery.

How to use this
Read the modules in order — each builds vocabulary the next one assumes you already have. Every module page has adjustable code you can run yourself in Python (pandas / scikit-learn / NumPy), diagrams for every visual concept, and an "Advantages / Disadvantages" box for every algorithm so you know not just how it works but when to reach for it. To get a PDF: open any page and use your browser's Print → Save as PDF (a print-friendly layout is already built in).
